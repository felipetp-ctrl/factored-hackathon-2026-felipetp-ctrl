Per-step seconds (incremental run): branches 0.01, customers 0.33, products 0.21, transactions 2.29, complaints 0.3, call_center_interactions 0.65, daily_exchange_rates 0.02, gold 0.42.

The incremental run still rewrites each silver file (one Parquet per table); what it saves is the recomputation of untouched keys. At this size both take seconds; past ~100M rows silver would be partitioned so that only the touched partitions are rewritten.
